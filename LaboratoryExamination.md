## 📁 Google Drive

Google Drive serves as the central storage location for the laboratory examination files. It allows files to be organized into folders, accessed online, and shared through links when the appropriate permissions are enabled.

**Key functions:**
- Store and organize examination files.
- Keep documents and spreadsheets in one accessible location.
- Share files using links and manage access permissions.
- Support cloud-based file management.

## 📝 Google Docs

Google Docs is a word-processing tool used to create, edit, and format written documents. It supports structured content, headings, tables, and collaboration with other users.

**Key functions:**
- Create and format written documents.
- Arrange information in a clear and readable layout.
- Edit content and make revisions.
- Share documents for viewing or collaboration.

<div align="center">

<img src="https://img.shields.io/badge/GOOGLE%20DOCS-FFE6ED?style=for-the-badge&labelColor=C37495" alt="Google Docs">

</div>

## 📊 Google Sheets

Google Sheets is a spreadsheet application used to organize information in rows and columns. It supports formulas, calculations, tables, and basic data analysis.

**Key functions:**
- Enter and organize data in spreadsheet form.
- Use formulas to perform calculations.
- Format cells and tables for readability.
- Manage and analyze information efficiently.
