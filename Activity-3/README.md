## ♡ ACTIVITY OVERVIEW

This activity focused on creating a social media infographic and mini project documentation entitled **“Smart Waste, Smarter Future.”** The project presents a proposed Smart Waste Segregation System that aims to promote proper waste classification, segregation, monitoring, and collection.

I designed the infographic using appropriate colors, typography, icons, illustrations, and organized layouts to communicate the importance of proper waste management. It highlights the problem, proposed solution, waste categories, key features, and benefits of the system.

## ♡ WHAT HAVE I LEARNED?

Through this activity, I learned how to transform information into an engaging and easy-to-understand infographic. I improved my skills in organizing content, selecting appropriate color combinations, using typography, and incorporating icons and illustrations to communicate ideas effectively.

One challenge I encountered was presenting several details about the Smart Waste Segregation System without making the infographic look overcrowded. I addressed this by grouping related information, using short descriptions, and maintaining a consistent layout and color scheme.

In the future, I can apply these skills when creating educational materials, social media posts, presentations, and other digital content. I will continue improving my visual communication skills by exploring creative layouts and making information more accessible and engaging.
